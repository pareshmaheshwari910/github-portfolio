How I work

A repeatable analytical approach

01

Frame the decision

Clarify who will use the analysis, what decision it supports, and how success will be measured.

02

Establish data trust

Profile the source, define grain and joins, test edge cases, and document metric logic.

03

Build the analysis

Use transparent SQL, Python, and BI methods that can be reviewed and maintained.

04

Communicate the action

Translate findings into clear implications, limitations, and recommended next steps.
