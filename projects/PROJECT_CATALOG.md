## Minimum standard for every public project

Each repository should contain:

- A clear business problem
- Synthetic or public data
- Reproducible setup instructions
- Documented data model and assumptions
- SQL, Python, or BI implementation
- Validation and testing notes
- Screenshots or sample outputs
- Key findings and recommended actions
- Limitations and future improvements
- A confidentiality statement

## Suggested project maturity labels

- **Concept** — scope and design documented
- **Prototype** — working proof of concept
- **Portfolio-ready** — reproducible, documented, and visually polished
- **Maintained** — issues, releases, and improvements continue over time
