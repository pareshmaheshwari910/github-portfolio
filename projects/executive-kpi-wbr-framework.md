# Executive KPI and WBR Framework

## Portfolio objective

Show metric governance, BI design, business review ownership, variance analysis, and stakeholder communication.

## Business problem

Leaders receive inconsistent metrics from different teams, spend too much time reconciling definitions, and lack a repeatable way to turn weekly trends into actions.

## Framework components

- KPI dictionary
- Source-to-metric lineage
- Governed semantic layer
- WBR dashboard
- Automated commentary inputs
- Variance and root-cause workflow
- Action and owner tracker
- Data-quality status indicators

## Example KPI documentation

| Field | Description |
|---|---|
| KPI name | Plain-language metric name |
| Business definition | What the metric means |
| Numerator | Included events or entities |
| Denominator | Eligible population |
| Grain | Daily, weekly, seller, shipment, etc. |
| Owner | Accountable business owner |
| Source | Governed data model |
| Refresh | Expected availability |
| Known limitations | Exclusions and caveats |
