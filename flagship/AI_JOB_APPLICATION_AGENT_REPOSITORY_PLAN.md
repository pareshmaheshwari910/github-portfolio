# Flagship Repository Plan: AI Job Application Agent

## Why this should be first

This project is the strongest flagship because it combines:

- Python application development
- Workflow automation
- Data modeling
- Scoring and ranking logic
- Responsible AI controls
- Testing
- Streamlit product experience
- GitHub repository discipline
- A relatable real-world problem

## Public release strategy

### Release 0.1 — Portfolio-safe core

Include:

- Synthetic candidate profile
- Fictional job postings
- Job normalization
- Duplicate detection
- Fit scoring
- CLI commands
- SQLite database
- Daily Markdown report
- Unit tests

Exclude:

- Browser automation
- Real credentials
- Personal résumé files
- Real application history
- Gmail OAuth
- Employer-specific private data

### Release 0.2 — Application packet

Add:

- Evidence mapping
- Tailored résumé bullet suggestions
- Cover-letter draft
- Factual-verification report
- Human approval manifest
- Change invalidation when source facts are edited

### Release 0.3 — Dashboard

Add:

- Opportunity table
- Score explanation
- Status tracker
- Packet review screen
- Validation status
- Daily metrics

## Responsible automation principles

- Human review before external actions
- No unsupported résumé claims
- Approved-domain allowlist
- Clear audit trail
- Reproducible scoring
- Configuration outside source code
- No credential storage in Git
- Safe failure when verification fails
